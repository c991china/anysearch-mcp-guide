# 进阶配置

除了基础接入，AnySearch MCP 还支持以下进阶用法。

## 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `ANYSEARCH_API_KEY` | 你的 API Key（必填） | 无 |
| `ANYSEARCH_MODEL` | 使用的模型名 | 由服务端决定 |
| `ANYSEARCH_TIMEOUT` | 单次请求超时（秒） | `30` |
| `ANYSEARCH_MAX_RESULTS` | 单次搜索返回条数上限 | `10` |

## 限流与重试
- 服务端对并发有限制，建议在客户端做指数退避。
- 遇到 `429` 时等待后再试，不要立即高频重试。

## 常见坑
- Key 必须走 Bearer 鉴权，不要写进要公开的代码里。
- 超时设置过短会在弱网下频繁失败，建议 ≥ 20s。
